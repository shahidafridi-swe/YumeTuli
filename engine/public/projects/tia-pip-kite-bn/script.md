# টিয়া আর পিপ: গাছে আটকে যাওয়া ঘুড়ি

- Format: 9:16 kids story, ~35s, Bangla (localized from tia-pip-kite-en)
- Characters: টিয়া (Tia), পিপ (Pip — ছোট্ট নীল হাতি)
- Same illustrations as English version

## Narration
1. এ হলো টিয়া! টিয়া তার লাল ঘুড়ি ওড়াতে খুব ভালোবাসে।
2. শোঁ শোঁ! জোরে বাতাস এলো... আর ঘুড়িটা আটকে গেল উঁচু গাছে!
3. টিয়া লাফায় আর লাফায়। কিন্তু ঘুড়িটা অনেক উঁচুতে।
4. তখন এলো ছোট্ট হাতি পিপ। "আমি সাহায্য করবো!"
5. টিয়া উঠলো পিপের পিঠে। পিপ তার লম্বা শুঁড় তুললো, উপরে, আরও উপরে!
6. পেয়ে গেছি! ঘুড়িটা নেমে এসেছে! হুররে!
7. এখন টিয়া আর পিপ একসাথে ঘুড়ি ওড়ায়। বন্ধুরা সবসময় একে অপরকে সাহায্য করে!
