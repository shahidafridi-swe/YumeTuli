# AGENTS.md

This repository's canonical guidance for AI agents lives in **`CLAUDE.md`**.

Read **`CLAUDE.md`** at the repo root first, then the `CLAUDE.md` nearest the files you are editing:

- `api/CLAUDE.md` — Laravel API, jobs, Claude runs
- `web/CLAUDE.md` — Next.js UI + BFF
- `engine/CLAUDE.md` — Remotion engine (video house rules in `engine/AGENTS.md`)

They define the six invariants, the spec-driven workflow with two human gates, the repo map and commands.
Slash commands, subagents and permission guardrails are under `.claude/`. Specs: `docs/specs/`. ADRs: `docs/adr/`.
