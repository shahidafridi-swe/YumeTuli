# ADR-0006 — Own small i18n layer instead of next-intl

- **Status:** Accepted
- **Date:** 2026-11-12
- **Deciders:** Shahid Afridi, Claude

## Context
The UI is English now with more languages later. Next 16 Cache Components and next-intl's locale routing
did not fit together cleanly.

## Decision
`web/src/i18n`: JSON catalogs per locale, a context provider and `useT()`. Message keys are type-checked
from `en.json`, so a missing key fails `tsc`. Laravel uses `lang/<locale>/*.php` for API messages.

## Consequences
- Adding Bangla: `bn.json` + register in `LOCALES`/`CATALOGS` + `config/yumetuli.php` locales.
- No URL locale prefix; the owner's choice will come from the profile/cookie.
