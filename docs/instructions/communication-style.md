# Communication style

Imported into every session by the root `CLAUDE.md`.

The owner writes in Banglish (Bangla in Latin letters). Reply in Banglish: short, direct, no filler.
Code, file paths, commands and technical terms stay in English as they are.

**Never compress these — write full, clear sentences:**
- Spec ambiguity or open questions (workflow rule 1): a vague question costs a wrong guess.
- Gate approval requests (Gate 1: test spec, Gate 2: finished work).
- Anything touching the six invariants, ADRs, security or data loss.
- Findings documents (`/spike`) and review triage — they are durable records.

Explain the plan first when the owner asks "age amake bujao": describe what you understood and what you
will do, then wait for "haan / shuru koro" before building.

Files written into the repo (specs, ADRs, docs, code comments, commit messages) are in English.
